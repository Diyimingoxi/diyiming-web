# DIYIMING Consultores - publicación en Vercel

## Antes de publicar

Confirme con el cliente estos datos y reemplácelos si corresponde:

- Correo oficial (actualmente `contacto@diyiming.com`).
- Dominio definitivo (actualmente se usa `diyiming.com` en sitemap y robots).
- Dirección, teléfono, WhatsApp y enlaces de redes sociales.
- Casos reales, cifras, clientes y autorizaciones para publicarlos.
- Textos legales y política de privacidad, si se recopilarán datos.

## Publicar hoy con Vercel

1. Ingrese a https://vercel.com y cree una cuenta o inicie sesión.
2. En el panel, seleccione **Add New > Project**.
3. Si ya subió esta carpeta a GitHub, seleccione **Import Git Repository** y elija el repositorio.
4. Si usa Vercel CLI, abra una terminal dentro de esta carpeta y ejecute `npx vercel`.
5. En la configuración del proyecto:
   - Framework Preset: **Other**
   - Root Directory: deje la carpeta del sitio
   - Build Command: déjelo vacío
   - Output Directory: déjelo vacío
6. Seleccione **Deploy**.
7. Vercel entregará una dirección temporal terminada en `.vercel.app`. Revise todas las páginas.

## Conectar el dominio

1. En Vercel abra el proyecto y vaya a **Settings > Domains**.
2. Escriba el dominio del cliente.
3. Vercel mostrará los registros DNS que deben configurarse en el proveedor del dominio.
4. Copie esos registros exactamente y espere la verificación.
5. Cuando el dominio sea definitivo, actualice `robots.txt` y `sitemap.xml`.

## Formulario

La versión actual no guarda datos: abre el programa de correo del visitante con el mensaje preparado. Antes de publicar, confirme el correo real del cliente. Si se necesita envío automático sin abrir el correo, conecte un servicio como Formspree o una función de Vercel y publique una política de privacidad.
